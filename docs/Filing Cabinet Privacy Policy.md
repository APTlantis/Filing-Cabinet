# Filing Cabinet Privacy Policy

**Effective date:** August 21, 2026

Filing Cabinet is a local-first desktop application developed by Aptlantis for preserving and managing files and their associated metadata.

## Information Filing Cabinet Accesses

Filing Cabinet may access files and folders that you explicitly choose to add to, inspect with, restore from, or otherwise manage through the application.

Depending on how you use the application, Filing Cabinet may also process information associated with those files, including:

- file names and paths
- file sizes and timestamps
- cryptographic hashes
- tags and categories
- notes and custom metadata
- extracted text from supported file types
- locally generated thumbnails and preview information
- vault health, verification, and repair information

This information is used solely to provide Filing Cabinet's local vault, search, verification, recovery, and organizational features.

## Local Storage

Filing Cabinet is designed to operate locally.

Retained files are stored in a vault location selected by the user. Catalog data, generated metadata, thumbnails, extracted text, verification results, and repair information are stored locally on the user's computer or storage devices.

Filing Cabinet does not require an Aptlantis account, cloud service, or remote storage service to operate.

## Data Collection and Transmission

Filing Cabinet does not transmit your vault contents, retained files, extracted text, notes, tags, file metadata, or other vault information to Aptlantis.

Aptlantis does not collect, sell, rent, or share Filing Cabinet vault data with third parties.

Filing Cabinet does not contain advertising or third-party tracking functionality.

## Cryptographic Hashing and Verification

Filing Cabinet may compute cryptographic hashes or compatibility checksums for files stored in or inspected by the vault.

These values are generated locally and are used for purposes such as:

- identifying retained content
- detecting changes
- verifying file integrity
- identifying duplicate content
- comparing files against existing checksum records

Hash values generated by Filing Cabinet are not automatically transmitted to Aptlantis.

## File Content and Extracted Text

For supported file types, Filing Cabinet may extract text or generate preview information to improve local search and navigation.

This processing occurs locally.

Filing Cabinet does not upload retained file contents or extracted text to Aptlantis for analysis.

## Repair, Recovery, and Logging

Filing Cabinet may maintain local information about vault health, verification results, repairs, rescans, quarantine actions, and other maintenance operations.

These records are used to make changes to the vault understandable and auditable.

They remain part of the user's local Filing Cabinet data.

## User Control

You control which files are added to Filing Cabinet and where your vault is stored.

You may inspect, copy, restore, quarantine, export, or delete retained information using Filing Cabinet's available tools.

Because Filing Cabinet stores its primary data locally, access to and backup of that information remains under the control of the user and the operating system.

## Microsoft Store Services

If Filing Cabinet is installed or obtained through the Microsoft Store, Microsoft may independently process information related to Store operation, installation, licensing, updates, diagnostics, or Store analytics.

That processing is controlled by Microsoft and is governed by Microsoft's own terms and privacy policies.

Aptlantis does not control data collected independently by Microsoft through Microsoft Store services.

## Security

Filing Cabinet is designed to keep its vault and catalog data on local storage.

Users are responsible for securing their computer, Windows account, vault location, backups, and any removable or network storage used with Filing Cabinet.

Filing Cabinet is not a replacement for a backup system, disk encryption, access controls, or other operating-system security measures.

## Changes to This Policy

This privacy policy may be updated if Filing Cabinet's data-handling behavior changes.

Any material change involving the collection, transmission, or sharing of user information will be reflected in an updated version of this policy.
